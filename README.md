# 内厨司｜AI 菜谱与做菜助手安卓版

内厨司是一款安卓做菜软件，支持 AI 菜谱推荐、一周食谱、备餐计划、冰箱库存、用餐成本和菜谱导入。首页助手“神厨小福贵”可以先推荐、讨论菜品，再按你的明确要求安排某顿饭。

Neichusi is an Android cooking assistant for AI recipe recommendations, weekly meal planning, meal prep, food inventory and meal cost tracking. Bring your own supported AI provider API key.

当前版本：**0.1.4**。普通用户可直接安装 APK，无需运行源码；AI 功能需要配置自己的模型服务，服务商可能收取调用费用。本项目不提供免费模型额度。

## 下载与开始使用

请到 [Releases](https://github.com/mwm1403882009-rgb/neichusi/releases) 查看已发布的 APK 安装包，文件名为 `neichusi-android-0.1.4.apk`。如果列表为空，表示安装包尚未发布。请勿把源码 ZIP 当作安装包。

1. 使用 Android 8.0 或更高版本手机打开 APK 并安装；如果系统要求，按提示允许当前下载工具安装应用。
2. 在“更多 → 模型设置”配置自己的服务商和 API Key。
3. 录入冰箱库存，向小福贵询问菜谱或安排餐次；核对用料，确认已吃后才计入花费并扣库存。

已有版本请先导出备份，再覆盖安装，**不要先卸载**。自行编译的 APK 使用自己的签名，不能直接覆盖维护者签名版本。

## 版本与功能基准

功能基准：微信小程序2026.10.22-r1；80项原始输入文件指纹记录在baseline.json。保留安卓专用的图片Base64适配、WAV录音、加密存储、业务读取缓存和用料输入合并保存。

首页助手为“神厨小福贵”，欢迎语为“皇上万福金安，神厨小福贵听候吩咐。”。支持连续问答、多道菜候选、选中后安排和收藏。推荐不自动写某餐，日期餐次不清楚时先补充；明确安排仅保存草稿，匹配库存和已知价格，确认已吃后才记账、扣库存。已确认和其他用餐不被自动覆盖。

实际用餐增加自炒/其他类型核对。外食明确保存为other，包括0元；不生成菜谱、不扣库存，替换原自炒记录时撤回原耗材。周汇总同日同餐去重，兼容旧记录缺类型或只有确认餐次的情况。未确认安排不计为已吃，不凭0元判断外食；明确自炒或有自炒用料证据的历史不被草稿改写类型。

## 安装与更新

将neichusi-android-0.1.4.apk复制或发送到安卓手机，在文件管理器打开安装。已有版本直接覆盖，不要先卸载；更新前建议从“更多”导出备份。包名cn.neichusi.app不变，versionCode为5，使用同一发布证书。应用仍名“内厨司”，首次安装不含个人记录、示例库存或模型密钥。

支持Android 8.0（API26）及以上，要求Android System WebView/Chrome内核100或更新。纯鸿蒙不能安装APK；无需区分arm64/x86安装包。未上架应用商店，安装包通过仓库 Releases 分发。

在“更多 → 模型设置”配置自己的服务商地址和Key。原有设置无需重新填写。支持DeepSeek、MiMo、Kimi、GLM、HY、Qwen及独立的小米语音设置；命中/未命中缓存、输出、语音与搜索分别估算计费，以服务商账单为准。

## 主要功能

- 神厨小福贵：文字/语音/图片、连续问答、多菜比较、明确指定餐次、收藏、采购和用餐草稿。
- 一周食谱：按周保存、午晚餐、外食卡片、可编辑做法、批次成本匹配、实际用餐统计、确认扣库存。
- 我的菜谱：食材分类、手动或外部内容导入、历史餐导入、照片封面。
- 冰箱库存：购物式列表、滑动操作、常买、采购批次、剩余盘点、图片/小票/语音、到期信息。
- 公开菜谱读取：同步当前小程序的公开正文/H5解析、有限跳转与回退、正文与公开图片合并、失败诊断。取得原文后再识别，不凭标题补写菜谱。

小红书链接不保证每次取得正文。登录、验证、限流、失效或访问拒绝时会停止，并可补充正文/截图。安卓公开网页请求独立于模型API：仅HTTPS白名单GET，不携带模型认证头或Cookie，不自动跳转；正文读取器逐跳核对目标。模型请求仍限制服务商白名单，发生跳转不转发密钥。没有增加登录、Cookie导入或验证绕过。

## 本地数据与隐私

APK内置React界面，原生层负责本地存储、网络、录音和照片，无需电脑或微信运行。数据与主动记住的Key由Android Keystore支持的AES-GCM加密保存在本App私有目录；不记住Key时仅留当前进程内存。没有账号服务器、云同步、遥测或广告。只有主动调用模型时发送相应文字、图片和上下文；语音用小米ASR转写，费用由用户自己的服务商账户承担。

仅声明联网与麦克风权限。相册用系统选择器按文件授权，拍照交由系统相机；照片封面复制到App私有目录，不自动发给模型。

App与小程序不自动同步。小程序备份JSON可以在App“更多 → 恢复备份”导入，导入会覆盖现有业务数据，先备份并核对。微信私有照片路径不能跨App读取，需重新添加。JSON备份不含Key及照片文件；换机/卸载前另存重要照片。卸载会清除App本地数据与照片。

## 构建与源码

client包含已经移植的独立客户端，native包含Activity/照片Provider/网络请求策略，scripts是构建打包工具，tests是回归检查。普通构建不需要小程序工程。

构建脚本面向 Windows，建议使用 PowerShell 7。安装Node.js22+，然后执行：

```
npm install
pwsh -File scripts/prepare-tools.ps1
node --test tests/*.test.mjs
pwsh -File scripts/build-apk.ps1
```

准备脚本从Eclipse Adoptium和Google官方源取得JDK17、Android35与Build Tools35.0.0并校验摘要，工具放在.tools，不改全局PATH。纯Java网络策略测试使用.tools/jdk；其他用户应先准备工具再跑全部测试。构建使用aapt2、javac、D8、zipalign与apksigner。

维护者显式重新迁移时才运行：

```
node scripts/sync-baseline.mjs --baseline=2026.10.22-r1
```

脚本核对请求版本与小程序来源版本，不静默同步后续版本。保留安卓图片、录音、空白初始数据和周输入性能适配。兼容入口复用基准中的助手实现，不维护两份独立业务逻辑。源码包不含微信工程配置、AppID、个人数据、密钥或签名材料。公开源码不含小程序来源工程，普通用户无需运行迁移命令。
